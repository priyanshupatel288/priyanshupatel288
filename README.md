I'm a **Software Developer** who builds the backend of real business software — the APIs, databases and workflows that accounting, payroll, ERP and CRM teams depend on every day.

My main stack is **Java + Spring Boot**, and I also ship with **Node.js, PHP, React and Next.js** on top of **MySQL** and **MongoDB**. I've worked across **Accounting, ERP, Payroll, CRM, E-commerce, LMS and EdTech** products, owning features from database schema and REST API design through frontend integration, auth, deployment and production support.
